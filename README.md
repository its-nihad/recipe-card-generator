# YumCard

YumCard is a single-file recipe card generator. Fill in a title, description, ingredients, and steps on the left, and watch a styled, printable recipe card build itself on the right in real time. It's built as one self-contained HTML file with no external libraries or fonts, so it runs straight from the file system or from GitHub Pages with nothing to install.

The card supports three themes: brass and parchment, verdant and cream, and midnight and gold, each with its own accent colors and paper tone. You can attach a photo of the finished dish, and there's a servings scaler that recalculates ingredient amounts (including fractions like 1 1/2) when you switch between half, single, double, or triple portions.

Once a card looks right, it can be sent to the printer with a clean print layout, or exported as its own standalone HTML file so it can be shared, archived, or dropped into another page. The generator opens with a sample recipe already filled in, so the card is never blank on first load.
